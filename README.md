​⏳ Age Calculator
​An interactive tool that calculates your exact age in years, months, and days based on your birth date. This project combines fast C++ logic with a modern, responsive web interface built using HTML and CSS.
​Features
​High Precision: Accurately calculates your age broken down into years, months, and days.
​Sleek Interface: Clean, user-friendly design for an intuitive experience.
​Fast Performance: Reliable computation powered by C++.

​Built With
​C++: Handles backend processing and calculation logic.
​HTML5: Structures the user interface and input fields.
​CSS3: Styles the application with a clean, modern look.

​How It Works
​Input your birth details (day, month, and year) into the designated fields.
​The application computes the difference between the current date and your date of birth.
​The exact age breakdown appears instantly on the display.

## 📌 About The Project

This project is a modern, interactive web application built for **Idea Academy**. Created entirely using core web technologies without relying on heavy external frameworks, it features a custom Dark Glassmorphism UI, high-performance animations, an interactive particle background canvas, and seamless responsiveness across all screen sizes.

---

## ✨ Key Features

* 🎨 **Dark Glassmorphism & Neon UI:** Modern glass-effect styling paired with aesthetically pleasing dark-theme visual accents.
* ⚡ **Lightweight & High Performance:** Built with clean Vanilla JavaScript for optimal rendering speed and minimal load times.
* 📱 **100% Fully Responsive:** Flawless cross-device compatibility across smartphones, tablets, laptops, and desktop displays.
* 🌌 **Interactive Particle Background:** Dynamic canvas-driven particle system providing a futuristic ambient design.
* 📝 **Interactive Registration Form:** Smooth, user-friendly registration and contact interface.
* 🧭 **Fluid Navigation:** Intuitive scroll behavior and smooth section transitions.

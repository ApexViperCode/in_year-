​⏳ Age Calculator
​An interactive tool that calculates your exact age in years, months, and days based on your birth date. This project combines fast C++ logic with a modern, responsive web interface built using HTML and CSS.
​Features
​High Precision: Accurately calculates your age broken down into years, months, and days.
​Sleek Interface: Clean, user-friendly design for an intuitive experience.
​Fast Performance: Reliable computation powered by C++.

​🛠️ Built With
​C++: Handles backend processing and calculation logic.
​HTML5: Structures the user interface and input fields.
​CSS3: Styles the application with a clean, modern look.

​How It Works
​Input your birth details (day, month, and year) into the designated fields.
​The application computes the difference between the current date and your date of birth.
​The exact age breakdown appears instantly on the display.














🐍 Snake Game in C++
​An interactive console version of the classic Snake game developed in C++. Test your speed and focus as you steer the snake to collect food while avoiding collisions with the boundaries or the snake's own body.
​✨ Features
​Smooth Controls: Responsive keyboard controls for instant directional changes.
​Dynamic Scoring & Growth: The snake grows longer and your total score increments each time food is eaten.
​Random Food Spawning: Food generates at random coordinates within the game board.
​Collision & Manual Exit Logic: Automatically detects boundary and self-collisions. Pressing the X key immediately stops the game with a loss.
​🛠️ Built With
​C++: Handles overall game logic, board grid array rendering, movement loops, and collision rules.
​🎮 How to Play & Controls
​Use the arrow keys or W, A, S, D to move the snake.
​Guide the snake to food items on the screen to earn points and grow in length.
​Avoid hitting the wall borders or your own tail to stay in the game and set a high score.
​Press the X key at any point to quit the game and forfeit immediately.
